# Packaged G1 runtime assets

> **Visual revision (2026-11-27):** current scene sources/derivatives are listed in [g1/VISUAL-SOURCES.md](g1/VISUAL-SOURCES.md). The table below also retains the earlier G1 assets/history; old tree and paving files are not the revised scene’s active foliage/materials.

These files ship with the actual application. They are not downloaded from an external CDN at runtime. Do not treat the project's official visual reference as a reusable game texture or asset source.

Runtime source also constructs original wordmarks, portal accents, sky reflection, plaza inlays and small petal clusters. The petals are an early original art treatment, **not an accepted realistic flowering-tree specimen**. No proprietary game extraction, paid model, unverified marketplace package or restricted motion/demo code is included.
