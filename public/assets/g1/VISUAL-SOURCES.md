# G1 visual revision source and rights record

2026-11-27. This supplements, not replaces, the retained A1/G1 source record and `../licenses/`.

- `landmark-v2.glb`: height-adjusted derivative of original CodeVerse `landmark.glb`. No real-world branded architecture or proprietary game model was extracted.
- `site-v2.glb`: original authored facade, glazing/frame recesses, entry canopy/doors, terraces, paving, ramps, curbs, extended road, street furniture, planters, static orbital sculpture and distant architectural context. Recipe: `scripts/g1/build-environment.mjs`. Distant context is visual scenery, not playable buildings or an expanded city system.
- `v2-{stone,basalt,asphalt,timber,bark,fabric,grass}-{color,normal,roughness}`: original deterministic generated surface maps. No photographic texture inputs. Recipe: `scripts/g1/build-visual-surfaces.mjs`. Several maps are embedded in the GLBs; standalone authoring outputs are retained.
- `v2-sky-{0..5}.rgba`: six original 128 × 128 RGBA directional-noise sky faces, generated by the same recipe. No downloaded HDRI. Environment irradiance is explicitly authored in the game; this is not a measured lighting capture.
- `canopy-v2.glb`, `blossom-v2.glb`, `underplanting-v2.glb`: new seeded CodeVerse presets/exports using Daniel Greenheck's MIT EZ-Tree source, pinned commit `dcf309bd86bd521083d9c70f01f2de45fdc7c457`. Leaf image `ash_color.png` from the previously inspected npm `@dgreenheck/ez-tree@1.1.0` package, hash-matched during A1 to the source LFS reference. Blossom leaf coloration is an original pink derivative of that image, **not a botanical flowering-tree scan**. Bark is original generated imagery, not ambientCG bark. Retain `../licenses/ez-tree-MIT.txt` and `../licenses/ez-tree-texture-notice.txt`. Recipe: `scripts/g1/build-vegetation.mjs`.
- `hero.glb`: approved MakeHuman/MPFB 2.0.18 **CC0 core graphics data** with original CodeVerse garment shells, hair, glasses, shoe details and joint cycles. Source archive hash and current output hash are in `hero-provenance.json`. MPFB program logic is GPL and is not distributed as game runtime code. This is direct core-data authoring, not a claimed Blender/MPFB export, professional garment package or licensed third-party motion. Retain `../licenses/makehuman-core-CC0.txt` and `../licenses/mpfb-license-distinction.txt`.

All inputs were already approved/cached or originally authored; no paid acquisition or new marketplace package was introduced. Licenses apply to their respective inputs, not blanket rights over every project file. The concept image is a design reference only and is not embedded as runtime art. No trademark/personality-right clearance is implied by CC0.

Current packaged hashes/bytes: `docs/evidence/g1-visual/runtime-assets.json`. Old `docs/evidence/g1/runtime-assets.json` is historical and must not be used to validate the revised binaries.

## Detailed graphics revision (current runtime)

This section supersedes the v2 runtime list above; the old files/records remain historical inputs.

- `site-v3.glb`: original curved curtain-wall renovation, 4.5 m deep furnished office bays, stone/bronze envelope, canopy construction, roof termination, paving variation, urban street-front blocks and gardens. Recipe `scripts/g1/build-detailed-environment.mjs`.
- `hero-urban.glb`: Microsoft Rocketbox **Male Adult 04** (dark casual jacket/hood, cyan shirt, brown trousers and trainers), body/head normal and color textures and opacity texture, plus compatible `m_idle_breathe_01`, `m_walk_neutral_01`, `m_run_neutral_01` motions. **MIT, Copyright (c) 2020 Microsoft**; retain `../licenses/rocketbox-MIT.txt`. Official repository `https://github.com/microsoft/Microsoft-Rocketbox`, commit `0943055db6ec570bcef9f2c8b41c9e5467c808f9`. Exact upstream filenames and SHA-256 in `docs/evidence/g1-graphics/character-source.json`. Assimp WASM converts FBX offline; CodeVerse converts TGA, consolidates buffers, rescales skeleton/geometry/bind matrices to metres and extracts in-place X/Z motion while retaining Y bob. This is not a newly scanned face, bespoke clothing or foot-IK system. Recipe `scripts/g1/build-urban-hero.mjs`.
- `canopy-v3.glb`, `oak-v3.glb`, `blossom-v3.glb`, `underplanting-v3.glb`: revised seeded MIT EZ-Tree presets using the same audited source/leaf inputs as v2. Higher branching, varied species silhouette, smaller/desaturated blossom and denser shrubs. Retain the existing EZ-Tree notices. Recipe `scripts/g1/build-natural-vegetation.mjs`.
- `daylight-urban.env`: offline GGX/RGBD cubemap derived from **Pedestrian Overpass**, Greg Zaal / Poly Haven, **CC0** (`https://polyhaven.com/a/pedestrian_overpass`). The 1K HDR input was obtained from the three.js example mirror, Git blob `4d119b90c784cafd83c0cf0bdb226f8a285d1380`. The CC0 asset license is distinct from GPL-licensed Poly Haven add-on code; no add-on code is used. Recipe `scripts/g1/build-daylight.mjs` integrates spherical irradiance and roughness mip levels. Original procedural sky imagery remains the visible background, while this measured HDR supplies material lighting. The pinned HDR source is restored to ignored authoring cache, not copied into the playable build.

Current packaged hashes/bytes: `docs/evidence/g1-graphics/runtime-assets.json`. Normal build/play uses only packaged files; authoring tools/downloads are optional. Original game behavior is unchanged; background blocks remain non-playable scenery. Software-browser evidence is not a physical gaming-laptop benchmark or a claim of AAA quality.

## Connected district / persistent-camera revision (latest)

The latest `site-v3.glb` is generated by `scripts/g2/build-district.mjs`, reusing the original facade and approved surface inputs. It now includes eight original surrounding parcels, connected asphalt/sidewalk cells, intersections, street furniture and bounded garden routes. These exterior streets are walkable; building interiors beyond the existing entrance interaction are not new playable rooms. The more distant skyline remains scenery. No new third-party asset or license was introduced. Rocketbox character, botanical inputs, HDR and their notices are retained unchanged.

**Latest packaged hashes/validation:** `docs/evidence/g2/runtime-assets.json`. Earlier manifests and reports describe their historical binaries and are not validation of the current site. Do not overwrite the district by running the older site builder. The optional district recipe writes `.cache/g3/site-district.glb`; copy that validated result to `public/assets/g1/site-v3.glb` and rebuild. `src/game/districtLayout.ts` supplies the shared authored parcel/street-furniture plan.
